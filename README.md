# FastAgent

这是 Fast Agent，欢迎大家提贡献。


FastAgent 是一个面向实践的学习项目，欢迎通过示例、文档和练习共同完善它。

## 快速开始

运行欢迎示例：

```bash
python3 examples/hello_fastagent.py
```

预期输出：

```text
Hello, FastAgent! Welcome to FastAgent.
```

仓库中的 `PYTHON知识点与练习网站` 文件还提供了 Python 知识点和练习入口。
